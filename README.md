## 🏗️ Architecture

The application follows a **full-stack architecture**, connecting a modern React frontend with a Node.js and Express backend.

```text
┌──────────────────────┐
│      React + Vite    │
│      Frontend        │
└──────────┬───────────┘
           │
           │ API Requests
           ▼
┌──────────────────────┐
│   Node.js + Express  │
│      Backend         │
└──────────┬───────────┘
           │
           │ Database Operations
           ▼
┌──────────────────────┐
│       MongoDB        │
│       Database       │
└──────────────────────┘
```

The architecture is designed with a focus on **separation of concerns, maintainability, and future scalability**.
